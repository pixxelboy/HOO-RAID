# Screenshot Guide

This folder contains images for the README and documentation.

## Required Images

Please capture the following screenshots from a running HOO-Raid plugin:

### Banner Image
- **Filename**: `hoo-raid-banner.png`
- **Size**: 1200x400px recommended
- **Content**: Logo/title graphic for the project header

### Main Screenshots

| Filename | Description | Recommended Size |
|----------|-------------|------------------|
| `screenshot-main.png` | Main dock with preset selector and Pick Random button | 400x600px |
| `screenshot-preview.png` | Streamer preview card showing all details | 400x600px |
| `screenshot-filters.png` | Filter editor dialog with all fields | 400x500px |
| `screenshot-greylist.png` | Greylist manager with some entries | 400x400px |

### Tips for Good Screenshots

1. **Use a clean OBS setup** - Hide other docks for cleaner shots
2. **Use dark theme** - Matches most streamers' setups
3. **Show realistic data** - Use actual streamer info (with permission)
4. **Crop to content** - Remove unnecessary window chrome
5. **Save as PNG** - Lossless compression, sharp text

### Creating the Banner

You can create a banner using:
- Canva (free)
- Figma (free)
- Photoshop
- GIMP

Suggested elements:
- "HOO-RAID" title text
- Tagline: "Because who to raid sometimes needs a fast answer"
- Raid/arrow iconography
- Purple/Twitch-inspired color scheme
